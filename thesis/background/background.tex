\chapter{Background}
\section{Reinforcement Learning}

Reinforcement learning (RL) studies sequential optimisation problems in
which an agent learns a policy from reward feedback, usually using the
Markov Decision Process (MDP) as the mathematical model
\cite{sutton2018reinforcement,kaelbling1996reinforcementlearningsurvey}.

\subsection{Markov Decision Processes}

A Markov Decision Process is a tuple
$(\mathcal{S},\mathcal{A},P,R,\gamma)$, where $\mathcal{S}$ is the state
space, $\mathcal{A}$ the action space, $P(s'|s,a)$ the transition
dynamics, $R(s,a)$ the reward function, and $\gamma\in[0,1)$ the
discount factor \cite{puterman2014markov,sutton2018reinforcement}. The
Markov assumption is that the next state and reward depend on the
current state and action rather than the full interaction history. A
policy $\pi(a|s)$ maps states to action distributions, and the standard
objective is to find a policy that maximises expected discounted return:
\[
\pi^\ast = \arg\max_\pi \mathbb{E}_{\pi}\Bigg[ \sum_{t=0}^\infty \gamma^t r_t \Bigg].
\]
The state-value and action-value functions encode the same objective
from a given state or state-action pair:
\[
V^\pi(s) = \mathbb{E}_\pi \Bigg[ \sum_{t=0}^\infty \gamma^t r_t \,\Big|\, s_0 = s \Bigg], \qquad
Q^\pi(s,a) = \mathbb{E}_\pi \Bigg[ \sum_{t=0}^\infty \gamma^t r_t \,\Big|\, s_0 = s, a_0 = a \Bigg].
\]
They satisfy the Bellman equations, which express value recursively in
terms of immediate reward and future value
\cite{bellman1957dynamic,sutton2018reinforcement}:
\[
V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \Big[ R(s,a) + \gamma \sum_{s' \in \mathcal{S}} P(s' \mid s, a) V^\pi(s') \Big],
\]
\[
Q^\pi(s,a) = R(s,a) + \gamma \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \sum_{a' \in \mathcal{A}} \pi(a' \mid s') Q^\pi(s',a').
\]

\subsection{Model-Free vs Model-Based Reinforcement Learning}

RL algorithms can be broadly divided into model-free and model-based
approaches \cite{sutton2018reinforcement,moerland2022modelbasedreinforcementlearningsurvey}.
Model-free methods learn policies or value functions directly from
observed transitions, as in Q-learning, actor-critic methods, and
policy-gradient algorithms
\cite{watkins1992qlearning,Williams1992SimpleSG,konda1999actor}. They
avoid modelling the environment, but can be sample-inefficient because
all improvement must come from real or logged interaction data.

Model-based RL instead learns approximations of the transition dynamics
and reward function,
\[
s_{t+1} \sim \hat{P}_\phi(s_{t+1} \mid s_t, a_t), \qquad r_t \approx \hat{R}_\psi(s_t, a_t).
\]
This internal model can then be used to simulate imagined trajectories
and choose actions by maximising predicted return
\cite{dyna,deisenrothpilco}:
\[
\hat{G}_t = \sum_{k=0}^{H} \gamma^k \hat{R}_\psi(s_{t+k}, a_{t+k}),
\]
\[
a_t = \arg\max_a \mathbb{E}_{\tau \sim \hat{P}_\phi}[\hat{G}_t \mid a_0 = a].
\]
Model-based approaches can improve sample efficiency and enable
counterfactual reasoning, but their reliability depends on the accuracy
of the learned model, especially when imagined rollouts are used over
long horizons \cite{daw2011model,moerland2022modelbasedreinforcementlearningsurvey}.

\subsection{Continuous Control and Actor-Critic Methods}

Deep value-based RL methods such as DQN were developed primarily for
small discrete action spaces, where action selection can be performed by
evaluating $Q(s,a)$ for every possible action
\cite{mnih2013playingatarideepreinforcement,mnih2015humanlevel}:
\begin{equation}
    a^* = \arg\max_{a \in \mathcal{A}} Q(s,a)
\end{equation}
For continuous robotic control, exhaustive maximisation is no longer
tractable: discretising $d$ action dimensions into $k$ bins produces
$k^d$ actions, and directly optimising $Q(s,a)$ at every step is a
non-convex problem
\cite{lillicrap2019continuouscontroldeepreinforcement}. Actor-critic
methods address this by learning both a policy, the actor, and a value
function, the critic \cite{konda1999actor}. The actor proposes actions
directly, while the critic supplies the learning signal used to improve
those actions. This is the central architecture used throughout the
thesis, although the later chapters replace simple Gaussian actors with
chunked and flow-based generative policies.

\section{Goal-Conditioned Reinforcement Learning}

\subsection{Goal-Conditioned RL Formulations}

Standard reinforcement learning assumes a fixed reward function $r(s,a)$, implicitly defining a single task \cite{sutton2018reinforcement}. This formulation is inherently restrictive, as it requires retraining an agent for each new objective. Goal-conditioned reinforcement learning (GCRL) addresses this limitation by extending the problem to a multi-task setting, where the objective is specified by a goal variable $g$ \cite{Kaelbling1993LearningTA, pmlr-v37-schaul15, plappert2018multigoalreinforcementlearningchallenging}. The agent is thus trained to achieve arbitrary goals within a shared environment.

Formally, this can be expressed by augmenting the state space to include the goal, yielding an augmented state $(s, g) \in \mathcal{S} \times \mathcal{G}$. The reward function becomes goal-dependent:
\begin{equation}
    r(s, a, g)
\end{equation}
and the policy is conditioned on both the state and goal:
\begin{equation}
    \pi(a \mid s, g)
\end{equation}
A common instantiation defines the reward as a distance to the goal, for example:
\begin{equation}
    r(s, a, g) = -\| f(s') - g \|,
\end{equation}
where $f(s')$ extracts a goal-relevant representation of the next state \cite{nair2018visualreinforcementlearningimagined, pong2020skewfitstatecoveringselfsupervisedreinforcement}. This formulation connects to early work on goal-directed behaviour, where the objective is to minimise the distance to a desired state \cite{Kaelbling1993LearningTA}.

Universal Value Function Approximators (UVFAs) provide a practical mechanism for learning in this setting by parameterising the value function over both states and goals \cite{pmlr-v37-schaul15}:
\begin{equation}
    Q(s, a, g; \theta) \approx Q^*(s, a, g).
\end{equation}
By leveraging function approximation, UVFAs enable generalisation across goals, allowing the agent to infer how to reach previously unseen targets \cite{pmlr-v37-schaul15}. This generalisation is critical for scaling RL to multi-task and goal-driven scenarios.

\subsection{Hindsight Experience Replay (HER)}

Despite its flexibility, GCRL suffers from a fundamental challenge: sparse rewards. In many environments, the agent only receives a non-zero reward upon reaching the exact goal, making successful experiences exceedingly rare during early training \cite{her,plappert2018multigoalreinforcementlearningchallenging}. As a result, naive learning becomes highly inefficient.
Hindsight Experience Replay (HER) addresses this issue by reinterpreting failed trajectories as successful ones for alternative goals \cite{her}. Given a trajectory $\tau = (s_0, a_0, \dots, s_T)$ collected while attempting to reach a goal $g$, HER relabels transitions by replacing $g$ with a goal $\tilde{g}$ that was actually achieved later in the trajectory \cite{her}. The reward is then recomputed as:
\begin{equation}
    r(s, a, \tilde{g}).
\end{equation}
This relabelling strategy increases the density of meaningful learning signals by turning each trajectory into supervision for many possible goals \cite{her,nair2018visualreinforcementlearningimagined}. It also motivates the off-policy data reuse that becomes central in offline reinforcement learning, where agents learn entirely from fixed datasets \cite{levine2020offlinereinforcementlearningtutorial}.

\subsection{Offline Reinforcement Learning and Implicit Q-Learning}
\label{sec:iql}
Offline reinforcement learning considers the setting where an agent must learn exclusively from a static dataset $\mathcal{D}$ of transitions, without further interaction with the environment \cite{levine2020offlinereinforcementlearningtutorial}. While appealing in practice, this setting is dominated by one central difficulty: distributional shift. The learned policy may select actions that are not well represented in the dataset, leading to erroneous Q-value estimates and compounding errors during training \cite{fujimoto2019offpolicydeepreinforcementlearning, kumar2019stabilizingoffpolicyqlearningbootstrapping}.

Standard off-policy algorithms such as Q-learning or actor-critic methods are particularly susceptible to this issue, as they rely on evaluating and maximising over actions that may lie outside the data distribution. Prior approaches, such as Conservative Q-Learning (CQL), address this by explicitly penalising Q-values for out-of-distribution actions \cite{kumar2019stabilizingoffpolicyqlearningbootstrapping, kumar2020conservativeqlearningofflinereinforcement}. However, these methods can be overly restrictive and difficult to tune.

Implicit Q-Learning (IQL) instead avoids explicit evaluation of unseen actions altogether \cite{kostrikov2021offlinereinforcementlearningimplicit}. Rather than performing a maximisation over actions, IQL decomposes learning into three components: a state-value function $V(s)$, an action-value function $Q(s,a)$, and a policy $\pi(a|s)$.
The key idea is to estimate the value function using expectile regression, which performs asymmetric least squares to approximate the upper expectile of the Q-function \cite{kostrikov2021offlinereinforcementlearningimplicit}:
\begin{equation}
    \mathcal{L}_V = \mathbb{E}_{(s,a) \sim \mathcal{D}} \left[ \rho_\tau \left( Q(s,a) - V(s) \right) \right],
\end{equation}
where $\rho_\tau(u)$ is the expectile loss:
\begin{equation}
    \rho_\tau(u) = |\tau - \mathbb{I}(u < 0)| u^2.
\end{equation}
This biases $V(s)$ toward higher Q-values without requiring an explicit maximisation.
The Q-function is then trained using a standard Bellman backup:
\begin{equation}
    \mathcal{L}_Q = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}} \left[ \left( Q(s,a) - (r + \gamma V(s')) \right)^2 \right].
\end{equation}
Finally, the policy is extracted via advantage-weighted regression \cite{peng2019advantageweightedregressionsimplescalable,nair2021awacacceleratingonlinereinforcement}:
\begin{equation}
    \mathcal{L}_\pi = \mathbb{E}_{(s,a) \sim \mathcal{D}} \left[ \exp\left( {\beta} (Q(s,a) - V(s)) \right) \log \pi(a|s) \right],
\end{equation}
which encourages the policy to imitate actions with high advantage.
By avoiding explicit queries of out-of-distribution actions, IQL achieves stable and effective learning in the offline setting \cite{kostrikov2021offlinereinforcementlearningimplicit}. This stability is the reason IQL-style value learning is used as a building block in the goal-conditioned and hierarchical methods of this thesis.

\subsection{Offline-to-Online Reinforcement Learning}
\label{sec:offline-online-bg}

While offline RL extracts a useful initialisation from a fixed dataset, the resulting policy is in general suboptimal: it can only do as well as the best actions from the data allow. Offline-to-online RL is a two-phase process that uses the offline policy as a starting point for further improvement via interaction with the environment, typically by continuing to update the same actor and critic on a growing buffer that combines the original dataset with newly collected transitions \cite{nair2021awacacceleratingonlinereinforcement, levine2020offlinereinforcementlearningtutorial, nakamoto2024calqlcalibratedofflinerl}.

The main difficulty is distribution shift between the two phases. Offline algorithms learn under a conservative prior that prevents the policy from straying too far from the data. When this prior is relaxed in the online phase, the critic's Q-values become unreliable on the new states the agent visits, and naive fine-tuning can destabilise or collapse the offline policy entirely \cite{nair2021awacacceleratingonlinereinforcement, nakamoto2024calqlcalibratedofflinerl}.

% Cal-QL \cite{nakamoto2024calqlcalibratedofflinerl} addresses this by explicitly calibrating Q-values during pretraining so the offline critic is well behaved at transition time. AWAC \cite{nair2021awacacceleratingonlinereinforcement} retains the offline behaviour-regularisation term throughout the online phase.

\section{Hierarchical Reinforcement Learning}

\subsection{The Curse of Long-Horizon Planning}

While goal-conditioned policies provide a mechanism for generalisation across tasks, they remain fundamentally limited when applied to long-horizon problems. In particular, as the temporal distance between the current state and the goal increases, the learning problem becomes significantly more difficult \cite{SUTTON1999181, nachum2018dataefficienthierarchicalreinforcementlearning}. In offline GCRL, this manifests as a rapid degradation in the signal-to-noise ratio of the value function for distant goals: value estimates become increasingly dominated by extrapolation error rather than meaningful supervision.

This issue is closely related to temporal credit assignment \cite{sutton2018reinforcement}. When rewards are sparse and delayed, the agent must propagate learning signals across many intermediate transitions. In flat architectures, where a single policy is responsible for both high-level planning and low-level control, this creates a bottleneck: the policy must implicitly learn multi-step reasoning over long horizons from a single decision-making process \cite{vezhnevets2017feudalnetworkshierarchicalreinforcement, nachum2018dataefficienthierarchicalreinforcementlearning}. As the horizon increases, errors in value estimation compound recursively, leading to unstable or overly conservative policies. This limitation becomes particularly severe in offline settings, where the agent cannot correct its behaviour through additional environment interaction.

\subsection{Foundations of Hierarchical Reinforcement Learning}

Hierarchical reinforcement learning (HRL) addresses this limitation by introducing temporal abstraction. Instead of relying on a single flat policy, HRL decomposes decision-making into multiple levels operating at different temporal resolutions \cite{BartoMahadevan2003, SUTTON1999181}. The classical formulation of this idea is captured by the options framework, which generalises Markov Decision Processes to include temporally extended actions, or ``options'' \cite{SUTTON1999181}. Each option consists of a policy, a termination condition, and an initiation set, allowing the agent to reason over higher-level behaviours rather than primitive actions.

In modern deep RL, this idea is often implemented as a bipartite hierarchy \cite{vezhnevets2017feudalnetworkshierarchicalreinforcement, nachum2018dataefficienthierarchicalreinforcementlearning, levy2019learningmultilevelhierarchieshindsight}. A high-level policy operates at a lower frequency, selecting intermediate subgoals or waypoints, while a low-level policy executes primitive actions to achieve these subgoals. Formally, the high-level policy selects a subgoal $g_t$ every $k$ steps:
\begin{equation}
    g_t \sim \pi_H(g \mid s_t),
\end{equation}
while the low-level policy conditions on both the current state and the subgoal:
\begin{equation}
    a_t \sim \pi_L(a \mid s_t, g_t).
\end{equation}

\subsection{Hierarchical Implicit Q-Learning (HIQL)}

Extending hierarchical RL to offline settings introduces additional challenges \cite{park2024hiqlofflinegoalconditionedrl}. In particular, both the high-level and low-level policies are subject to distribution shift: the high-level policy may propose subgoals that are not supported by the dataset, while the low-level policy may be required to execute actions that lie outside the behaviour distribution. These issues make extensions of HRL to offline data unstable and prone to compounding errors.

A primary reason non-hierarchical policies struggle with distant goals is the ``signal-to-noise'' ratio in the value function \cite{park2024hiqlofflinegoalconditionedrl}. When a goal is far away, the optimal action is often only marginally better than suboptimal actions. Consequently, small errors in the learned value function can drown out this signal, leading to an erroneous policy. Hierarchical Implicit Q-Learning (HIQL) mitigates this by decomposing the policy into two levels, enabling the value function to provide clearer learning signals for both \cite{park2024hiqlofflinegoalconditionedrl}. 

A distinguishing feature of HIQL is that it extracts all necessary components---a representation function, a high-level policy, and a low-level policy---from a single goal-conditioned value function \cite{park2024hiqlofflinegoalconditionedrl}. Instead of treating subgoals as raw, high-dimensional states, HIQL introduces a latent encoder $\phi(\cdot)$ and defines a value function over these representations:
\begin{equation}
    V(s, \phi(g))
\end{equation}
The hierarchy operates across a temporal offset of $k$ steps. The high-level policy, conditioned on the current state $s_t$ and the ultimate goal $g$, predicts a latent representation of a $k$-step future subgoal $z_{t+k} = \phi(s_{t+k})$:
\begin{equation}
    z_{t+k} \sim \pi^h(z_{t+k} \mid s_t, g)
\end{equation}
The low-level policy then takes this latent subgoal representation as input to produce primitive actions:
\begin{equation}
    a_t \sim \pi^l(a_t \mid s_t, z_{t+k})
\end{equation}
Both levels are extracted from the shared value function using an Advantage-Weighted Regression (AWR) style objective, avoiding explicit maximisation over out-of-distribution actions \cite{peng2019advantageweightedregressionsimplescalable, park2024hiqlofflinegoalconditionedrl}. The high-level policy optimises for subgoals that maximise the value difference towards the final goal, with its advantage approximated as $A^h \approx V(s_{t+k}, g) - V(s_t, g)$. The low-level policy optimises for actions that successfully reach the nearby subgoal, utilising the advantage $A^l \approx V(s_{t+1}, s_{t+k}) - V(s_t, s_{t+k})$.

For this thesis, the important consequence is the separation between
state-sequence learning and motor grounding. Because the high-level
policy treats future states as subgoal actions, the value function and
high-level policy can be trained from passive state trajectories without
action labels \cite{park2024hiqlofflinegoalconditionedrl}. Action-labelled
data is needed only by the low-level policy, which grounds the latent
subgoals in executable controls.

\section{World Models}

World models are model-based RL approaches in which an agent learns an
internal model of environment dynamics and uses it to plan, reason, or
optimise behaviour through simulated trajectories
\cite{sutton2018reinforcement, moerland2022modelbasedreinforcementlearningsurvey, ha2018worldmodels}. This paradigm was popularised by Ha and Schmidhuber, who trained policies inside a learned latent ``dream'' environment \cite{ha2018worldmodels}.

\subsection{Learning Latent Environment Dynamics}

A world model typically decomposes the problem into three components: a perceptual encoder, a dynamics model, and a controller or policy \cite{ha2018worldmodels, hafner2019planet}. Given high-dimensional observations $o_t$ (e.g.\ image frames), an encoder maps observations into a latent state
\[
z_t = f_\phi(o_t),
\]
where $z_t$ captures the features of the environment necessary for prediction and control. This compression reduces the dimensionality of the modelling problem and filters out irrelevant visual details \cite{ha2018worldmodels, hafner2019planet}.

The latent dynamics model predicts how the environment evolves under actions \cite{hafner2019planet,hafner2020dreamer}. Given the current latent state $z_t$ and action $a_t$, the model estimates a distribution over the next latent state:
\[
p_\theta(z_{t+1} \mid z_t, a_t).
\]
In early world models, this transition function is parameterised by a recurrent neural network (RNN) with stochastic outputs \cite{ha2018worldmodels}. The recurrent hidden state $h_t$ summarises past information, creating transitions of the form
\[
p_\theta(z_{t+1} \mid z_t, a_t, h_t),
\qquad
h_{t+1} = g_\theta(h_t, z_t, a_t).
\]
This formulation allows the model to capture both stochasticity and temporal dependencies in the environment.

Action selection is handled by a controller or policy $\pi_\psi(a_t \mid z_t, h_t)$, which is deliberately kept lightweight to encourage the world model to handle most of the complexity. In the original formulation, the controller is a linear mapping
\[
a_t = W_c [z_t, h_t] + b_c,
\]
with parameters optimised to maximise cumulative reward, often using optimisation methods such as evolutionary strategies \cite{salimans2017evolutionstrategiesscalablealternative, ha2018worldmodels}. This separation highlights a key principle of world models: intelligence is concentrated in the learned dynamics, while control remains simple.

While this formulation demonstrated the feasibility of learning and planning in latent spaces, modern approaches have significantly evolved. Contemporary world models replace recurrent architectures with Transformer-based sequence models, which are better suited to capturing long-range temporal dependencies and scaling to large datasets \cite{hafner2025dreamerv4}. Similarly, simple linear controllers are replaced with powerful reinforcement learning algorithms such as Soft Actor-Critic (SAC) or advantage-weighted regression methods, enabling more expressive and adaptive policies \cite{haarnoja2018softactorcriticoffpolicymaximum, peng2019advantageweightedregressionsimplescalable,hafner2020dreamer}. Modern systems therefore rely on high-capacity models for both dynamics and control, rather than on handcrafted simplicity.

The main motivation for operating in latent space is efficiency. Modelling directly in pixel space is computationally expensive and forces the model to reconstruct visually irrelevant details (e.g.\ textures or lighting variations) that are not important for control \cite{hafner2019planet,hafner2020dreamer,LeCun2022APT}. By contrast, latent representations focus on task-relevant structure, enabling more efficient learning, better generalisation, and more stable long-horizon prediction.

\subsection{Joint-Embedding Predictive Architectures}
\label{sec:jepa}

Traditional world models, particularly those based on variational autoencoders or latent generative models, aim to reconstruct observations at the pixel level while learning dynamics \cite{kingma2022autoencodingvariationalbayes,ha2018worldmodels,hafner2019planet,hafner2020dreamer}. While effective, this objective is often unnecessarily complex: reconstructing every pixel requires modelling high-frequency visual details that are irrelevant for decision-making.
Joint-Embedding Predictive Architectures (JEPAs) propose a fundamentally different approach \cite{LeCun2022APT}. Instead of reconstructing observations, JEPA models learn to predict future latent representations directly \cite{assran2023selfsupervisedlearningimagesjointembedding}. Given an encoded state $z_t$, the model predicts a future embedding $z_{t+1}$ (or further into the future), focusing only on the abstract features necessary for downstream tasks. This avoids the overhead of pixel-level reconstruction and shifts the learning objective toward capturing semantic and dynamical structure. Figure~\ref{fig:jepa-bg} contrasts the two designs.

However, this formulation introduces a critical challenge: representation collapse \cite{grill2020bootstraplatentnewapproach, chen2020exploringsimplesiameserepresentation}. If the model is trained solely to minimise the distance between predicted and target embeddings, it can trivially satisfy the objective by mapping all inputs to a constant vector. In this degenerate solution, predictions are always correct, but the representation carries no useful information.
Standard JEPA-style methods address this issue through architectural and optimisation tricks, such as using exponential moving average (EMA) target networks or applying stop-gradient operations to prevent collapse \cite{grill2020bootstraplatentnewapproach, chen2020exploringsimplesiameserepresentation}. While effective, these techniques introduce additional complexity and can make training brittle \cite{maes2026leworldmodelstableendtoendjointembedding}.

\subsection{Model Predictive Control with World Models}
\label{sec:mpc-bg}

Model Predictive Control (MPC) replaces a learned policy entirely with an online optimisation problem solved at each decision step \cite{rawlings2017model, Camacho:1999}. Given the current state $z_t$, a candidate action sequence $\mathbf{a}_{t:t+H}$ is rolled out for $H$ steps through the learned dynamics $f_\psi$, and the resulting trajectory is scored by a learned value or reward \cite{chua2018deepreinforcementlearninghandful, hafner2019planet}. The first action of the best sequence is executed and at the next step, the procedure is repeated from the new state \cite{rawlings2017model}. Formally,
\begin{equation}
    \mathbf{a}^{\star}_{t:t+H} \;=\; \arg\max_{\mathbf{a}_{t:t+H}} \; J\!\big(z_t,\, \mathbf{a}_{t:t+H};\, f_\psi,\, Q_\theta\big),
    \quad \text{execute } a^{\star}_t,\; \text{replan at } t+1.
    \label{eq:mpc-objective-bg}
\end{equation}
What varies between MPC variants is how the candidate set is constructed and how the score $J$ is computed. The Cross-Entropy Method \cite{Rubinstein1999} maintains a Gaussian distribution over action sequences, samples from it, and refits to the elite subset. Model Predictive Path Integral control \cite{williams2015modelpredictivepathintegral} performs a similar fitting under a sampling-based importance-weighted update. More recent work integrates a learned value function into the score so that the planning horizon $H$ can stay short, and uses backpropagation through the learned model to refine the candidate by gradient ascent rather than re-sampling \cite{hansen2022temporaldifferencelearningmodel}.

\section{Action Spaces and Generation}
\label{sec:action-spaces-bg}

Robotic control policies must represent actions in a way that is both expressive and tractable for learning. In low-dimensional settings, a policy may output a single primitive action at each timestep, but this becomes limiting for manipulation tasks where behaviour depends on temporally extended, coordinated action sequences \cite{zhao2023learningfinegrainedbimanualmanipulation,chi2024diffusionpolicyvisuomotorpolicy}. Recent work therefore models actions as chunks or trajectories rather than isolated control commands, allowing policies to capture longer-horizon intent and reduce the ambiguity of single-step supervision \cite{li2026reinforcementlearningactionchunking}. This section reviews three action representations used in this thesis: action chunking, Flow Q-Learning, and flow-map policies with Q-guidance.

\subsection{Action Chunking and Q-Chunking}
\label{sec:qchunking-bg}

When offline data is generated by non-Markovian policies (e.g. human controlled demonstration), a policy trained on the offline data that conditions only on the current state can struggle to model the demonstrations \cite{zhao2023learningfinegrainedbimanualmanipulation, chi2024diffusionpolicyvisuomotorpolicy}. Individual actions often appear ambiguous because the demonstrator's longer-term intent is not directly observable. To address this issue, action chunking trains the actor to predict a sequence of $h$ consecutive primitive actions in a single forward pass \cite{zhao2023learningfinegrainedbimanualmanipulation,li2026reinforcementlearningactionchunking}. The predicted chunk is then executed open-loop, and the policy is queried again only after all $h$ actions have been completed \cite{zhao2023learningfinegrainedbimanualmanipulation, chi2024diffusionpolicyvisuomotorpolicy}.

Action chunking also changes how the critic is trained. Q-Chunking \cite{li2026reinforcementlearningactionchunking} treats the entire chunk as a single action and learns a chunk-level value function $Q_\theta(z_t, \mathbf{a}_{t:t+h})$ whose Bellman target uses an $h$-step return:
\begin{equation}
    Q_\theta(z_t, \mathbf{a}_{t:t+h}) \;\leftarrow\; \sum_{k=0}^{h-1} \gamma^{k}\, r_{t+k} \;+\; \gamma^{h}\, Q_{\bar\theta}\!\left(z_{t+h},\, \mathbf{a}_{t+h:t+2h}\right),
    \quad \mathbf{a}_{t+h:t+2h} \sim \pi(\,\cdot\mid z_{t+h}).
    \label{eq:qchunking-target}
\end{equation}
Because the Q-function is conditioned on the entire action sequence, the $h$-step backup remains unbiased in the same way as standard one-step temporal-difference learning. Unlike conventional $n$-step returns, which can introduce bias when learning from off-policy data, the target uses the exact action chunk whose return is being evaluated \cite{munos2016safeefficientoffpolicyreinforcement, sutton2018reinforcement}. As a result, chunk-level Q-learning propagates value information $h$ times faster than primitive-action methods without incurring the usual bias–variance trade-off.

\subsection{Flow Q-Learning (FQL)}
\label{sec:fql-bg}

Flow-matching policies provide a generative way to model complex action
distributions. Rather than predicting a single action directly, the
policy learns to transform a simple noise distribution into the
distribution of actions observed in the dataset. Given a state $z$, an
initial noise sample $x_0 \sim \mathcal{N}(0,I)$, and a dataset action
$\mathbf{a}$, flow matching defines an interpolation
\[
    x_t = (1-t)x_0 + t\mathbf{a}, \qquad t \in [0,1],
\]
between noise at $t=0$ and the target action at $t=1$. A neural network
$u_\xi(z,x_t,t)$ is trained to predict the velocity field that moves
samples along this path:
\[
    u^\star(x_t) = \mathbf{a} - x_0.
\]
This yields a simple regression objective, avoiding adversarial training
or likelihood estimation, while still allowing the policy to represent
multimodal action distributions \cite{liu2022flowstraightfastlearning,lipman2023flowmatchinggenerativemodeling,tong2024improvinggeneralizingflowbasedgenerative}.
At inference time, actions are generated by starting from Gaussian noise
and integrating the learned velocity field to obtain a sample from the
policy's action distribution.
Building on this idea, Flow Q-Learning (FQL) \cite{park2025flowqlearning} combines flow-matching behaviour cloning with value-based offline reinforcement learning \cite{lipman2023flowmatchinggenerativemodeling}. The method consists of a flow-based policy, a distilled one-step actor, and a TD-trained critic; Figure~\ref{fig:fql-bg} summarises the three components and their training signals.

\begin{figure}[t]
\centering
\includegraphics[width=0.85\linewidth]{figures/fql_pipeline.pdf}
\caption{Overview of Flow Q-Learning (FQL), in the notation of this
section. A behaviour-cloning flow $u_\xi$ is trained by flow matching

\label{fig:fql-bg}
\end{figure}

\paragraph{Behaviour-cloning flow.} FQL first trains a conditional flow-matching policy using the standard objective:
\begin{equation}
    \mathcal{L}_{\text{BC}}(\xi) \;=\; \mathbb{E}_{z, \mathbf{a}, x_0, t}\!\left[\,\big\|u_\xi(z, x_t, t) - (\mathbf{a} - x_0)\big\|_2^2\,\right],
    \quad x_t = (1-t)x_0 + t\,\mathbf{a},\; x_0\sim \mathcal{N}(0,I),\; t\sim\mathcal{U}[0,1].
    \label{eq:bc-flow-bg}
\end{equation} \cite{lipman2023flowmatchinggenerativemodeling}
Sampling requires integrating the learned velocity field from Gaussian noise to the final action \cite{lipman2023flowmatchinggenerativemodeling}.

\paragraph{One-step distilled actor.} To avoid expensive multi-step integration at inference time, FQL distils the flow into a one-step actor $\mu_\psi(z,x_0)$ \cite{park2025flowqlearning}. The actor is trained to remain close to the flow solution while being guided toward actions with high critic values:
\begin{equation}
    \mathcal{L}_{\text{distil}}(\psi) \;=\; \alpha\, \mathbb{E}_{z, x_0}\!\left[\,\|\mu_\psi(z, x_0) - \Phi_\xi(z, x_0)\|_2^2\,\right]\; -\; \mathbb{E}_{z, x_0}\!\big[\,Q_\theta(z, \mu_\psi(z, x_0))\,\big],
    \label{eq:fql-actor}
\end{equation}
where $\Phi_\xi$ denotes the integrated flow trajectory and $\alpha$ controls the strength of the behaviour-cloning regularisation.

\paragraph{Critic.} The critic is trained using chunk-level temporal-difference learning, with the distilled actor providing bootstrap actions:
\begin{equation}
    \mathcal{L}_{\text{critic}}(\theta) \;=\; \mathbb{E}\!\left[\,\Big(Q_\theta(z, \mathbf{a}) - \big(r + \gamma^{h}\, Q_{\bar\theta}(z', \mu_\psi(z', x_0'))\big)\Big)^2\,\right].
    \label{eq:fql-critic}
\end{equation}
Following standard practice, FQL uses an ensemble of critics to reduce value overestimation \cite{hasselt2010double,haarnoja2018softactorcriticoffpolicymaximum}.

\subsection{Flow Map Policies and Q-Guidance}
\label{sec:fmq-bg}

Standard flow-matching policies parameterise an instantaneous velocity field $u_\xi(z,x_t,t)$ that must be integrated through many Euler steps to generate an action \cite{lipman2023flowmatchinggenerativemodeling}. Flow map policies \cite{ziakas2026aligningflowmappolicies} instead learn a velocity that directly transports a sample between two points in time.
This formulation includes conventional flow matching as a special case and allows actions to be generated in a single forward pass. Mean-flow policies \cite{ziakas2026aligningflowmappolicies} use this idea to amortise multi-step integration while preserving the expressiveness of flow-based policies.

To adapt a flow-map policy using value estimates, \cite{ziakas2026aligningflowmappolicies} formulates action improvement as a trust-region optimisation problem. Given a frozen reference policy, the goal is to find a velocity perturbation that increases the critic value while remaining within a radius of the reference.
The update moves the policy in the direction of the critic gradient while remaining inside the trust region \cite{ziakas2026aligningflowmappolicies}. By using the offline policy as the reference, the online actor can be trained to match this critic-guided target, providing a mechanism for policy improvement.

\section{Experimental Environment and Benchmarks}

\subsection{Physics Simulation and MuJoCo}

Reinforcement learning for robotics is fundamentally constrained by the cost and risk of real-world data collection. Physical experiments are slow, expensive, and often unsafe, particularly during early stages of learning when policies are highly exploratory \cite{kober2013reinforcement, dulacarnold2019challengesrealworldreinforcementlearning}. As a result, high-fidelity simulation has become the standard paradigm for developing and evaluating continuous control algorithms \cite{MUJOCO}.

MuJoCo (Multi-Joint dynamics with Contact) is a widely used physics engine for this purpose \cite{MUJOCO}. It provides accurate and efficient simulation of rigid body dynamics, supporting continuous control inputs such as joint torques, as well as complex contact interactions including friction and collisions. Crucially, MuJoCo enables fast simulation at scale, allowing agents to collect large amounts of data that would be infeasible in real-world settings \cite{MUJOCO}.

However, this realism comes at a cost: MuJoCo environments operate in high-dimensional continuous state and action spaces. Even moderately complex robotic systems involve multiple degrees of freedom, leading to an exponential increase in the size of the action space. This curse of dimensionality poses significant challenges for standard RL algorithms \cite{bellman1957dynamic, sutton2018reinforcement}.

\subsection{The Challenge of Robotic Manipulation}

Building on this simulation framework, robotic manipulation tasks introduce a set of additional challenges that make them particularly demanding benchmarks for reinforcement learning. Tasks such as object pushing, reaching, or pick-and-place require precise coordination across multiple joints, often resulting in high-dimensional action spaces \cite{kober2013reinforcement}. For example, controlling a robotic arm may involve 5 or more degrees of freedom, each of which must be optimised simultaneously.

A key difficulty arises from contact-rich dynamics \cite{Lynch_Park_2017}. Unlike simple locomotion tasks, manipulation involves interactions with external objects, where small errors in force or positioning can lead to highly nonlinear and unpredictable outcomes. Modelling and controlling these interactions is inherently challenging, especially in the absence of dense reward signals.

Furthermore, many manipulation tasks are long-horizon in nature. Successfully completing a task such as pushing an object to a target location or picking and placing a cube requires executing a sequence of coordinated actions over hundreds of time steps. Errors accumulate over time, and a single failure can invalidate the entire trajectory. This makes temporal credit assignment particularly difficult and motivates the use of hierarchical methods, which decompose long-horizon objectives into sequences of intermediate subgoals \cite{SUTTON1999181,sutton2018reinforcement,nachum2018dataefficienthierarchicalreinforcementlearning}.

\subsection{The OGBench Framework}
\label{sec:experimental-environment}

To evaluate performance in this setting, we adopt the OGBench framework, a benchmark suite specifically designed for offline goal-conditioned reinforcement learning \cite{ogbench_park2025}. Traditional offline RL benchmarks, such as D4RL \cite{fu2021d4rldatasetsdeepdatadriven}, focus primarily on task-conditioned settings where the objective is to maximise a fixed reward function (e.g.\ locomotion speed). While useful, these benchmarks do not capture the compositional and generalisation challenges inherent in goal-conditioned tasks \cite{her, ogbench_park2025}.

OGBench addresses this limitation by constructing datasets and evaluation protocols tailored to goal-reaching \cite{ogbench_park2025}. Instead of optimising a single objective, agents are trained to reach a wide range of target states sampled from the dataset. Offline data is typically generated using a mixture of exploratory or pseudo-expert policies, resulting in diverse but sub-optimal trajectories. During evaluation, goals are often sampled by selecting a future state from the same trajectory, requiring the agent to ``stitch together'' behaviours observed in the dataset \cite{fu2021d4rldatasetsdeepdatadriven, ogbench_park2025}.

This formulation places a strong emphasis on generalisation and compositional reasoning, as the agent must infer how to reach novel goals by recombining previously observed transitions. Importantly, the dataset structure aligns closely with hindsight relabelling strategies, enabling direct integration with methods such as HER \cite{her}.
In our implementation, we use the HGCDataset structure provided by OGBench, which is specifically designed for goal-conditioned learning \cite{ogbench_park2025}. This supports hindsight goal relabelling directly and keeps the training and evaluation protocols consistent.

\section{Related Work}

\subsection{World Models as Training Environments}

World models build on a long line of model-based reinforcement learning
methods in which learned dynamics are used for planning or policy
improvement \cite{dyna, ha2018worldmodels}. Recent advances
have scaled the capacity of latent dynamics models, allowing agents to
learn behaviours inside imagined environments rather than relying solely
on real-environment interaction \cite{hafner2020dreamer,hafner2025dreamerv4}.
Architectures such as DreamerV4 use high-capacity sequence models and
flow-based objectives to simulate complex interactions from raw pixels,
achieving strong performance through policy optimisation inside the
learned model \cite{hafner2025dreamerv4}.

However, using learned world models as environment substitutes
introduces fundamental vulnerabilities, notably compounding prediction
errors and model exploitation. Model-Based Policy Optimization (MBPO)
showed that compounding error can be controlled by branching many short
model rollouts from real dataset states instead of trusting long
imagined trajectories, with performance bounds that degrade as the
rollout horizon grows \cite{janner2019trust}; the short-horizon
constraint that recurs throughout this thesis is consistent with that
analysis. Theoretical analyses have also shown that
imperfect world models can be exploited by optimising policies, which
may discover actions that yield high predicted rewards under the model
but fail in the true environment
\cite{bhamidipaty2026imperfectworldmodelsexploitable}. To mitigate
compounding errors over long horizons, Model-Based RL with Action Chunks
(MAC) trains multi-step models to predict future states from entire
action sequences, rather than single actions
\cite{park2025scalableofflinemodelbasedrl}. This thesis characterises
these failure modes in goal-conditioned and offline-to-online settings,
and studies diagnostic mechanisms for safely using a single frozen
latent world model.

\subsection{Predictive Architectures and Latent Planning}

Generative world models often reconstruct high-dimensional observations,
whereas Joint-Embedding Predictive Architectures (JEPAs) predict in
representation space and avoid pixel-level reconstruction
\cite{LeCun2022APT,assran2023selfsupervisedlearningimagesjointembedding}. LeWM applies this
idea to control by training a stable end-to-end JEPA from pixels using
isotropic Gaussian regularisation
\cite{maes2026leworldmodelstableendtoendjointembedding}. Frameworks
such as Planning with Latent Dynamics Models (PLDM) show that
JEPA-trained world models can generalise to novel layouts and perform
trajectory stitching from reward-free offline data
\cite{sobal2025learningrewardfreeofflinedata}. Extending this predictive
paradigm, TD-JEPA bridges representation learning with temporal
difference learning, approximating successor features in latent space to
enable zero-shot optimisation across multiple policies
\cite{bagatella2025tdjepalatentpredictiverepresentationszeroshot}.
This thesis builds on LeWM as a frozen latent dynamics model, extending
its use beyond latent prediction to inference-time planning,
world-model-generated training data, and hierarchical subgoal
evaluation.

\subsection{Hierarchical Model-Based Control}

In long-horizon continuous-control tasks, the action search space grows
rapidly with planning horizon, limiting the effectiveness of flat
planning algorithms. Hierarchical reinforcement learning addresses this
problem through temporal abstraction, for example through options or
subgoal-conditioned policies \cite{SUTTON1999181,nachum2018dataefficienthierarchicalreinforcementlearning,park2024hiqlofflinegoalconditionedrl}.
Hierarchical Planning with Latent World Models (HWM) applies this idea
to world-model control by learning environment dynamics at multiple
temporal resolutions \cite{zhang2026hierarchicalplanninglatentworld}.
At inference time, HWM uses a high-level macro-transition model to
generate a sparse sequence of latent subgoals, which then guide a
low-level Model Predictive Control (MPC) planner
\cite{zhang2026hierarchicalplanninglatentworld}. This temporal
abstraction reduces inference latency and enables zero-shot execution on
complex robotic tasks.
In a similar vein, this thesis integrates a world model into a
hierarchical offline RL framework. Rather than learning a separate
macro-transition model, it uses short-horizon world-model rollouts to
evaluate candidate subgoals proposed by a high-level actor.

\subsection{Generative Policies and Offline-to-Online Adaptation}

Expressive generative models, such as diffusion and flow matching, have
become prominent in offline RL and imitation learning because they can
capture multimodal behavioural distributions
\cite{chi2024diffusionpolicyvisuomotorpolicy,lipman2023flowmatchinggenerativemodeling,tong2024improvinggeneralizingflowbasedgenerative}.
However, their iterative sampling procedures can introduce substantial
inference latency. Flow Q-Learning (FQL) accelerates generation by
distilling a behavioural flow-matching policy into a deterministic
one-step actor trained to maximise $Q$-values, avoiding unstable
backpropagation through the full generative trajectory
\cite{park2025flowqlearning}.

Alternatively, flow-map policies learn a direct map between points in
the generative-time interval, allowing large steps through the
generative dynamics. To adapt these one-step policies during online
fine-tuning, Flow Map Q-Guidance (FMQ) formalises adaptation as a
trust-region optimisation problem, yielding an analytically optimal
velocity perturbation that maximises the critic's $Q$-value while
remaining anchored to the offline prior
\cite{ziakas2026aligningflowmappolicies}. FMQ also introduces
Q-Guided Beam Search (QGBS), an inference-time refinement procedure
combining re-noising and beam search to explore high-value actions
\cite{ziakas2026aligningflowmappolicies}. This thesis uses the FMQ
optimal action update inside the learned world model's latent space to
perform offline-to-online fine-tuning without further real-environment
interaction.
